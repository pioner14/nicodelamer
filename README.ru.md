# Сайт Nico de la Mer (черновик)

Чистые HTML + CSS + немного JS. Без сборки и npm. Английский открывается на `/`, французский — `/fr/` (переключатель EN/FR в шапке). Тема светлая или тёмная: по системе, кнопка в шапке запоминает выбор.

```
index.html        главная на английском (по умолчанию); en/index.html — только переадресация на /
fr/               французская версия; en/ — английские юридические страницы
css/tokens.css    цвета, шрифты, отступы — всё оформление меняется здесь
css/main.css      стили
js/               фасад плеера, переключатель темы
assets/           картинки и шрифты
design/           макет Stitch (только внешний вид)
site.config.json  домен-заглушка; tools/set-domain.py меняет его везде
```

## Как запустить локально
```bash
cd ~/Projects/nicodelamer
python3 -m http.server 8000
```
Откройте http://localhost:8000/ . Сайт должен открываться с корня домена (пути вида `/css/main.css`), поэтому файлы напрямую двойным кликом не открывайте.

## Как поменять текст и добавить трек
- **Текст:** откройте `en/index.html` и `fr/index.html`, ищите `TODO(owner)` (комментарии) и `[...]` в квадратных скобках — это заглушки. Меняйте обе языковые версии.
- **Обложка:** положите `assets/img/sunset-sessions.webp` (1200×1200, ≤200 КБ) и поменяйте `src` у картинки в блоке `.cover`.
- **Ссылка на площадку:** кнопка «Open on [PLATFORM]» — впишите адрес в `href`.
- **Плеер:** в кнопке Play впишите `data-embed="https://www.youtube-nocookie.com/embed/ID"` (или `https://open.spotify.com/embed/album/ID`). Пока пусто — кнопка скрыта. Плеер грузится только по клику.
- **Соцсети:** сейчас ссылки ведут на главные страницы площадок. Замените на свои профили.
- **Три альбома в работе:** замените `[WORKING TITLE 1..3]` / `[TITRE DE TRAVAIL 1..3]`.
- **Новый трек:** отдельного списка треков нет (в данных владельца их нет). Добавите — это отдельная правка.
- **Шрифты:** Montserrat и Inter (OFL) лежат в `assets/fonts/`, подключены в `css/tokens.css`.

## Как опубликовать
1. Создайте репозиторий на GitHub и загрузите папку (`design/`, `*.zip` и `prompt-*` можно не загружать).
2. **Cloudflare Pages:** Workers & Pages → Create → Pages → Connect to Git → выберите репозиторий; команда сборки пустая, папка вывода — `/`. Файл `_headers` подхватится сам.
3. **GitHub Pages:** Settings → Pages → ветка `main`, папка `/ (root)`. Нужен свой домен или репозиторий `имя.github.io`: на адресе вида `/repo/` пути с `/` сломаются. `_headers` GitHub Pages не читает.
4. Перед запуском проверьте условия коммерческого использования на официальных страницах выбранного хостинга.

## Что сделать при покупке домена
1. `python3 tools/set-domain.py https://ваш-домен.com` — заменит `https://example.com` в canonical, hreflang, OG, sitemap, robots и JSON-LD.
2. Проверьте `sitemap.xml` и `robots.txt` в браузере.
3. Подтвердите сайт в Google Search Console и Bing Webmaster Tools, отправьте `sitemap.xml`.
4. Профиль Google Business — по желанию; адрес можно скрыть. Решение за вами.

## Если после правки CSS или JS сайт выглядит по-старому
GitHub Pages кэширует файлы до 10 минут, а браузер — дольше. В ссылках на `css/` и `js/` стоит `?v=ГГГГММДД`. После правок замените число на сегодняшнюю дату во всех `.html` (команда: `grep -rl "?v=" --include=*.html .`), тогда все увидят свежую версию сразу.
